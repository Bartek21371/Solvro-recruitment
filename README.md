# Zadania rekrutacyjne - DevOps

Repozytorium zawiera rozwiązania zadań rekrutacyjnych związanych z rolą DevOps.

[Zadania](https://github.com/Solvro/rekrutacja/blob/main/devops.md)

## Dokumentacja

Szczegółowy opis realizacji każdego zadania znajduje się w pliku '.pdf' w odpowiednim folderze repozytorium.
Sprawozdania zawierają:
- przebieg realizacji zadania,
- wykonane konfiguracje,
- przeprowadzone testy, 
- uzyskane wyniki i podsumowania.
